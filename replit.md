# Calamansi Juice Yield Predictor

## Run on Replit

The app runs as a Streamlit web application:

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 5000 --server.headless true
```

The Replit workflow is configured as **Start application** and serves the preview on port 5000.

The project includes its SQLite database, dataset, and trained model files in the repository. Python dependencies are listed in `requirements.txt`.
